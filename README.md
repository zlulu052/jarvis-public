# Jarvis Personal AI

一个以本地数据为核心的个人 AI PWA。

## 3 分钟部署自己的 Jarvis

### 1. 创建自己的仓库
点击页面顶部：

Use this template → Create a new repository

仓库名称可以填写：

jarvis-personal

---

### 2. 部署到 Vercel
登录 Vercel：

https://vercel.com

选择：

Add New → Project

然后导入刚刚创建的 GitHub 仓库。

点击：

Deploy

一般不需要修改其他设置。

---

### 3. 打开自己的 Jarvis

部署完成后，Vercel 会生成类似：

https://xxxx.vercel.app

打开这个地址即可使用。

手机用户可以使用 Safari 打开后：

分享 → 添加到主屏幕

---

## AI 功能

记录、标签、趋势、计划等基础功能不需要 API Key。

如果需要使用：

- AI 分析
- Jarvis 问答
- 图片识别
- AI 计划
- AI 洞察

请进入：

设置 → AI 服务设置

填写自己的 API Key。

每个人使用自己的 API Key，不会消耗作者的 API 额度。

---

## 数据存在哪里？

Jarvis 的主要个人数据保存在你自己的浏览器本地。

建议定期使用：

设置 → 导出备份

保存自己的 JSON 备份文件。

注意：使用 AI 分析时，相关内容仍需要发送给你所配置的模型服务。
